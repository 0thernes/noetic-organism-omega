# Verification Architecture (`docs/verification.md`)

`noetic-organism-omega v2.1.0` uses a six-layer defense-in-depth verification stack where no single test or proof stands alone:

1. **Compiler & Memory Safety Layer:** Portable C11 compiled cleanly under `-std=c11 -O3 -Wall -Wextra -Werror` on Win64 Clang 23 and Linux GCC; CI adds `-fsanitize=address,undefined` (`ASan`/`UBSan`), report-only static analysis (`cppcheck`/`clang-tidy`), and a standalone `libfuzzer` harness (`tests/fuzz_noetic_input.c`).
2. **Anti-LARP Negative Control & Property Layer:** `bin/noetic_engine test` catches `5/5` compiled mutants (`MUT-1..5`); `scripts/audit_zero_theater.mjs` scans `readout_metric()` for zero arm/ablation branching and `noetic_world_step()` for zero heap calls; `tests/noetic_prop.test.mjs` runs `prop_check` across 32 randomized seed/arm/ablation trials (96 frames) checking twin-run 0-bit SHA-256 determinism, `0 uq` drift, `0` 2nd-law violations, and 0-bit PCI\* non-interference.
3. **Statistical & Seed-Firewall Layer:** Disjoint seed partitions (`Dev 1001..1099`, `Confirmatory 5001..5024`, `Held-Out 5101..5124`) locked by a SHA-256 hash-chained burn-on-fail ledger (`GATE-01`), evaluated with exact DP Wilcoxon signed-rank tests (`T05`), paired bootstrap `d_z` 95% CIs, and Holm-Bonferroni step-down FWER.
4. **Full 825-Check & 100-Milestone Native C11 Layer:** All 9 Clean-Slate v3.0 suites (`825/825`, `0` fail) and `100/100` acyclic milestones execute natively in C11 with explicit `[INDICATOR-ONLY]` (`29`) and `PASS_CLASSICAL_PARITY_DISCLOSED` (`5`) epistemic tags.
5. **6-Kernel Palomar Lean 4.35.0 Formal Layer:** `54/54` theorems (`N01..N48` core + `N49..N54` non-vacuity/refutation witnesses) under `module` headers and isolated `Challenge.lean` / `Solution.lean`, verified across 5 independent local Windows checkers (`results/lean4-multi-kernel.txt`) and 6/6 Linux `bubblewrap` kernels in CI, with verbatim `#print axioms` parity enforced by `scripts/check_readme_axioms.py`.
6. **Publication, Citation & Provenance Layer:** Zero-overflow Tectonic AMS-LaTeX PDF (`scripts/build_paper.py`), clean-room `arxiv_submission.tar.gz` verification, 22/22 live DOI/URL verification (`scripts/check_citations.py`), `CHECKSUMS.sha256`, `data/MANIFEST.sha256`, `gitleaks`, and GitHub SLSA artifact attestations (`actions/attest-build-provenance@v2`).
